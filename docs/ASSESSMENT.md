# 通用化评估与后续改进

评估日期：2026-09-09。范围为本仓库的MCP、安装器、Skill和分发包，不修改用户正在使用的其他项目或现有MCP注册。

## 本次完成

|原问题|修改结果|
|---|---|
|Base URL固定，配置被忽略|支持供应商预设、自定义完整API前缀和环境变量|
|只支持单一供应商的Images接口|适配OpenAI Images、Gemini generateContent和聊天式图片输出|
|只接受Bearer鉴权|支持自定义Key请求头、环境变量头和显式无鉴权|
|默认向所有模型发送low、background、moderation等|通用模式省略未指定的可选字段，保留显式参数|
|自动选型和能力快照绑定单一供应商|优先显式或配置模型；移除专属默认型号、优先级和历史证据|
|没有/models的站点难以使用|允许关闭探测；探测失败时仍可使用配置模型|
|扩展参数及部署路由不可配置|增加extra_body、omit_fields、endpoints、query和header_env|
|改址可能带走旧凭据|配置文件连接整体优先；官方Key只自动用于官方域名；切换安装连接清除旧鉴权和路由|
|API跟随重定向、JSON响应无大小限制|API拒绝重定向；对响应流施加大小限制|
|配置解析异常绕过MCP错误封装|解析也在错误处理内；结果保持纯文本和结构化错误|
|参考图先读入内存再检查大小|先检查普通文件和大小，再读取|
|并发保存同名文件存在覆盖竞态|独占发布及冲突重试，保留完整结果|
|通用供应商错误语义不同可能触发重试|所有生成请求只提交一次，移除专属重试和异步探测|
|锁定依赖存在已披露漏洞|更新兼容依赖与hono覆盖版本，生产依赖审计重新执行|
|安装器更新会丢失其他配置字段|保留完整配置，支持选择供应商或导入JSON，并在持久化前校验|
|全局配置环境变量可能干扰已注册连接|MCP注册固定到该安装的配置路径；显式缺失配置报错而不回退|
|无鉴权网关可能意外保存环境中的Key|运行时忽略API Key，安装器清除Key及其环境变量引用|
|环境变量引用在Codex启动MCP时可能被过滤|注册所需`env_vars`名称并反读验证，不把环境中的凭据值写入Codex配置|

## 建议后续迭代

|优先级|改进|价值与边界|
|---|---|---|
|P1|加入多参考图和mask工具参数|提升真实编辑工作流；需要按协议和模型检查总大小、格式、数量|
|P1|专用异步任务适配器|为fal、Replicate等增加提交/状态/结果协议；需持久化任务ID和处理取消，避免重复计费|
|P1|可重复的授权在线兼容性矩阵|每供应商指定模型、输入和最大调用数，记录请求ID及实际像素；不能用一次成功宣称全站通用|
|P2|图像会话与任务恢复|长请求可保存任务状态并查询结果，减少宿主退出后重新提交；同步接口可能无法恢复|
|P2|多连接交互式配置管理|当前可使用多配置文件和多MCP注册；后续可提供脱敏列举、切换和校验命令|
|P2|代理与企业证书说明|当前沿用Node运行时网络配置；提供显式代理方案时需同时覆盖API和图片下载，保留DNS地址检查|
|P2|目录分页和能力元数据|目前目录保留返回ID，通用自动识别采用名称启发式；应增加供应商分页和模态字段，并继续允许显式模型|
|P2|跨平台安装器|Node代码支持Windows/macOS/Linux，但自动安装与ACL目前面向Windows|
|P3|结构化性能与费用统计|返回已有usage与耗时；费用单价会变化，不应硬编码为精确账单|

不建议做收到错误后自动换模型、改尺寸、换供应商或循环重试。这些动作会改变用户请求并可能重复计费，应由用户明确选择。
