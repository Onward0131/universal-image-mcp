## 连接与方法

- Base URL：`https://fengchao-api.com/v1`。
- Provider：`openai-compatible`；协议：`openai-images`。
- `GET /models`返回HTTP200，目录中可见`gpt-image-2`，测试使用该实际返回的型号。
- 通过真实MCP stdio客户端调用`image_doctor`、`generate_image`和`edit_image`；不是绕过MCP直接提交请求。
- 两次调用均指定`size=1024x1024`、`format=png`、`count=1`，配置请求超时480000ms，客户端等待上限600000ms。
- 文生图内容为白色背景的红色纸鹤；编辑以上一张图片为参考，要求只改为蓝色并保留形状、背景和阴影。
